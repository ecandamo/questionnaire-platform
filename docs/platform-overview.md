# API Sales Questionnaire Platform

## What It Is

An internal tool for **API sales reps** to send structured questionnaires to prospects and clients. Clients respond through a secure link — no login, no account setup.

It replaces the old workflow of **Excel spreadsheets sent back and forth over email**.

---

## The Problem

API's sales process requires structured information from clients — company details, financial context, ROI inputs, workshop logistics, and more. Today, that often means:

- **Excel files over email** — informal, easy to lose track of
- **Endless follow-up** — "Did you get my spreadsheet?" "Which version is current?" "Can Finance fill in section 3?"
- **Inconsistent discovery** — every rep sends a slightly different file
- **A weak first impression** — a generic spreadsheet doesn't match how API positions itself as a technology company

Sales reps spend time chasing answers instead of selling. Clients get a process that feels ad hoc, not enterprise-grade.

---

## What API Built

A questionnaire platform with two distinct experiences:

### For API Sales Reps (Internal)

Sales reps log in and can:

1. **Create** a questionnaire from a standard template or the shared question bank
2. **Attach** it to a client/prospect record
3. **Publish** and send a secure link
4. **Track** status — draft, shared, in progress, submitted
5. **Review** answers in one place
6. **Export** to CSV when needed
7. **Reopen** if the client needs to add or update information

The dashboard shows what's outstanding across deals. No digging through inboxes.

### For Clients (External)

Clients open the link and get:

- A branded, guided form (not a spreadsheet attachment)
- A progress bar and autosave
- Clear sections and required fields
- Support for text, numbers, currency, dates, selections, and file uploads
- **Team answering** — the primary contact can invite colleagues; each person sees only their assigned questions
- A confirmation screen when complete

No API account required. One link, professional experience.

---

## How It Solves the Problem

| Old Way (Excel + Email) | With the Platform |
|-------------------------|-------------------|
| Informal attachments | Structured, branded questionnaire |
| Lost threads and versions | One live link, one source of truth |
| Rep chases multiple people | Client can delegate sections to the right stakeholders |
| Inconsistent questions per rep | Standard templates + shared question bank |
| "Did you fill it out yet?" emails | Rep sees status; autosave reduces "I lost my work" |
| Feels like a small vendor | Feels like a proper technology company |

**Success looks like:** fewer follow-up emails, faster complete responses, and a discovery process that matches API's positioning.

## Built-In Questionnaire Types

Templates match common moments in the API sales cycle:

| Template | Purpose |
|----------|---------|
| **Data Request** | Standard prospect discovery — company, financials, operations |
| **Hobson ROI** | ROI analysis clients already know — current state, pain points, costs, payback expectations |
| **Workshop** | Plan a customer workshop — attendees, format, goals |
| **Pre-Workshop** | Prep intake before a workshop |
| **Custom** | Pick questions from the bank for a specific deal |

Reps start from a template, adjust if needed, and send.

---

## Typical Flow (Sales Rep Perspective)

```
1. New opportunity needs discovery
2. Rep creates questionnaire (e.g. Data Request or Hobson ROI)
3. Links it to the client
4. Publishes → copies secure link → sends to primary contact
5. Client opens link, answers (may invite Finance, IT, etc.)
6. Rep sees status change — reviews when submitted
7. Exports or references answers for next conversation
```

No spreadsheet versioning. No "which tab did you mean?"

---

## Collaboration (When Multiple People Need to Answer)

Common in B2B: one contact can't answer everything.

- Primary contact opens the questionnaire
- Invites colleagues (e.g. CFO for budget, IT for systems)
- Each person gets their own link and sees only their questions
- Primary contact tracks progress and submits when required sections are done
- Rep sees who contributed what

Less "please forward this Excel to your team" — more "here's your section, takes 10 minutes."

## What This Is — and Isn't

### It Is

- A questionnaire tool to gather client information efficiently
- A way to look and operate like the technology company API is

### It Is Not

- A CRM replacement (deals still live in your CRM)
- Contract signing or legal workflow
- Project management or delivery tracking

Discovery and intake only — done well.

---

## Why It Matters for API

Sales reps are the primary users. Their job is relationships and revenue, not spreadsheet logistics.

This platform:

- **Cuts follow-up email** — status and structure do that work
- **Standardizes discovery** — every rep sends the same quality intake
- **Elevates the client experience** — premium form, not an attachment
- **Supports complex B2B buying** — multiple stakeholders, one coordinated response
- **Preserves institutional knowledge** — questions live in a bank admins maintain, not in someone's Downloads folder

A client's first structured interaction with API shouldn't feel like 1998 email attachments. It should feel like working with a company that has its act together.
